# 🏠 膳待家 · Umami Skill for Health

把 [膳待家 Umami](https://github.com/renchenxuan/Umami) 装进你的 AI 编程助手——基于 [Agent Skills](https://agentskills.io) 标准（SKILL.md）构建的**对话式个人健康管家技能**。ZCode / Codex / Claude Code 装上它，就能管冰箱、出菜谱、记三餐、排训练、追体重、打卡目标与习惯；健康记录持久化到本地 SQLite，不注册、不上传，隐私归你自己。

> 🌐 **原版 Web 应用在这里**：[https://github.com/renchenxuan/Umami](https://github.com/renchenxuan/Umami)——`bun run dev` 一键启动、打开浏览器即用，带可视化面板、多会话与多模型管理，功能更完整。欢迎大家按喜好选用：**要界面用 Web 版，图顺手装本技能。**

## 为什么做这个技能

膳待家原本是一个「打开浏览器才能用」的 Web 应用。但程序员的健康需求往往出现在顺手的地方：写代码的间隙想记一笔刚吃的午饭，存完代码想问一句「冰箱里的五花肉还能放几天」。于是我们把它的核心能力封装成 Agent Skill——不用打开任何界面，在你和 AI 助手聊天的窗口里，膳待家就在了。

原 Web 项目保持独立、一行未改：本仓库通过只读导出复用它的食材大全，通过移植它的系统提示词、Agent 工具与安全边界，把「模型只做判断、副作用交给脚本」这同一套哲学，从 pi-agent 架构搬进了 skill 世界。

技能目前处于 **v0.1** 阶段，功能还在快速打磨中，难免粗糙——**欢迎大家使用**，无论是装上试试、提建议还是直接动手改（Issue / PR 都欢迎）。希望膳待家能陪你（和你的 AI 助手）一起，做一个更健康的程序员。

## 功能特性

- 🧊 **冰箱食材管理**：增删改查，按分类自动推断存放分区（肉类/水产冷冻、其余冷藏）与保鲜状态（新鲜/临期/已过期）
- 📸 **拍照识别食材**：发一张冰箱照片，助手识别并保存食材
- 📅 **菜谱 / 🛒 购物清单**：先读冰箱再推荐，优先消耗临期食材，过敏忌口是硬约束
- 🍚 **三餐饮食记录**：自动识别餐次，结构化落库
- 📊 **营养估算**：卡路里与三大营养素，写明份量假设与不确定性
- 🏋️ **训练计划与记录**：按目标、器械、天数生成，强调循序渐进与安全
- ⚖️ **身体数据追踪**：记录体重/体脂，结合趋势解读减脂增肌进度
- 🎯 **目标管理 / 💧 习惯打卡**：减脂增肌等目标状态跟踪，睡眠、饮水等日常记录
- 🛡️ **健康安全边界**：不做医疗诊断，紧急警示建议就医，营养只做估算不装权威
- 🔒 **本地优先**：数据存本机 SQLite，一条命令导出全部数据

## 技能结构

```
├── install.ps1 / install.sh          # 一键安装到 ~/.agents/skills/
├── examples/test-prompts.md          # 测试提示词与期望行为
├── tools/export-foods.ts             # 从原项目导出食材种子（只读）
└── skills/umami-health/
    ├── SKILL.md                      # 人设 + 铁律 + 命令速查 + 工作流 + 写操作分级
    ├── references/                   # 按需加载的领域知识
    │   ├── health-safety.md          #   医疗边界与紧急警示
    │   ├── recipe-workflow.md        #   菜谱 / 购物清单 / 拍照识别流程
    │   ├── fitness-workflow.md       #   训练计划流程
    │   ├── diet-logging.md           #   饮食记录与餐次推断
    │   └── nutrition.md              #   营养估算原则
    └── scripts/
        ├── health_db.py              # 单文件数据 CLI（纯 Python 标准库，零依赖）
        └── seed_foods.json           # 165 种中国常见食材（分类 / emoji / 默认单位）
```

## 快速开始

### 1. 安装

需要 Python 3.10+（仅标准库，无需 pip install）。

**Windows（PowerShell）：**

```powershell
.\install.ps1
```

**macOS / Linux：**

```bash
./install.sh
```

或手动把 `skills/umami-health/` 整个目录复制到 `~/.agents/skills/umami-health`，重启 AI 助手即可识别。

### 2. 开聊

首次涉及数据操作时，助手会自动执行 `init` 初始化数据库并内置食材大全，不用额外配置。

### 3. 数据在哪

| 优先级 | 位置 |
|---|---|
| 1 | 命令行 `--db` 参数 |
| 2 | 环境变量 `UMAMI_HEALTH_DB` |
| 3 | 默认 `~/.umami/health.db` |

所有记录只写本机 SQLite 文件，可随时用任意 SQLite 工具查看或备份。

## 使用示例

**饮食**：「冰箱里有鸡蛋、西红柿和青椒，帮我安排明天的三餐」／「中午吃了一碗牛肉面和一个苹果」／「分析一下今天的营养」

**健身**：「给我定个一周三练的减脂计划，无器械」／「记录今天慢跑 30 分钟」

**身体与目标**：「记录体重 72.5kg、体脂 20%」／「设个目标：减脂到 65kg」／「昨晚睡了 7 小时」

**安全**：「我最近头晕，吃什么好？」→ 助手不做诊断，会说明信息局限并建议就医方向。

## 设计说明

原 Web 应用到 Agent Skill 的翻译：

- **系统提示词**（膳待家人设、五大领域规则）→ `SKILL.md`
- **13 个 Agent 工具**（食材/收藏/偏好/营养/训练/身体/目标/习惯/饮食）→ `health_db.py` 的 12 组子命令，原版的取值校验一并移植
- **4 个内置技能**（健康指导/食谱推荐/健身推荐/饮食记录）→ `references/` 五篇文档，按需加载
- **写操作分级**：轻量记录直接执行；清空冰箱、改个人资料、归档记录先向用户确认
- **营养分析子调用** → 改为按 `references/nutrition.md` 由助手自行估算
- **不迁移**：Web UI、多会话、多模型管理——助手本身就是界面与模型入口

架构遵循 [anthropics/skills](https://github.com/anthropics/skills) 的官方模式：**确定性操作一律走打包好的脚本，模型只负责理解与判断**；领域知识放 `references/` 渐进加载，SKILL.md 保持精简。
