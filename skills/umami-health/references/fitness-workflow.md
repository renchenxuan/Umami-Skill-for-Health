# 健身推荐工作流

当用户想要训练计划、运动安排、动作指导或健身建议时，按以下流程执行。

## 流程

1. **先读身体与目标**：运行 `prefs get`（身高/年龄/性别/活动水平）、`body list --days 30`（近期体重体脂趋势）、`goals list` 与 `workouts list --days 14`，参考已有目标与训练，避免重复或冲突。
2. **按目标设计**：依据用户目标（减脂 / 增肌 / 保持 / 耐力）与器械条件（无器械 / 哑铃 / 健身房）安排力量、有氧、柔韧三部分。
3. **给出可执行的计划**：按天 / 按动作呈现，标注组数、次数与组间休息。
4. **记录习惯**：如用户认可计划并完成了训练，运行 `workouts log --activity … --duration …` 记录。

## 动作指导

讲解具体动作（如深蹲、硬拉）时覆盖：标准做法（分步骤）、常见错误、安全注意事项。

## 安全第一

- 对初学者强调循序渐进，从低强度开始加量。
- 明确写出"出现疼痛或不适应立即停止"。
- 不提供医疗诊断或伤病康复方案；涉及伤病、孕产、慢病等场景参考 `health-safety.md` 采取保守建议。

## 示例对话片段

> 用户：给我制定一个 3 天的减脂训练计划，无器械
>
> 助手：先运行 `body list` + `goals list` + `workouts list` → 结合体重趋势与目标输出 3 天分化计划（每个动作标注组数×次数×组间休息）→ 询问是否设为目标或记录今天的训练。
